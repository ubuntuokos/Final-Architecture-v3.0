# FA3 AutoGPT constrained current-host runtime

This directory materializes the production-candidate runtime for `FA3-PROVIDER-AUTOGPT-001`.

## Scope

The admitted surface is intentionally smaller than the full AutoGPT Platform:

- pinned upstream source: `autogpt-platform-beta-v0.7.3@f49bcca95ed327396d8ebdd0bdf7810de482ac1a`;
- real AutoGPT backend REST service and `/external-api/v1`;
- one deterministic allowlisted block: `StoreValueBlock` (`1ff065e9-88e8-4358-9d82-8dc91f622ba9`);
- ephemeral Postgres, three-node Redis cluster and RabbitMQ;
- no frontend, scheduler, graph executor, Copilot executor, marketplace execution, model calls, GPU passthrough or external runtime egress.

The provider is not an identity, authorization, MCP, secrets, model-routing, workflow, evidence, host-resource or registry authority.

## Isolation

The current-host harness builds a local AutoGPT backend image from the exact source commit using a base image resolved to a registry RepoDigest. Every dependency selector is resolved to a RepoDigest **before it is started**. The runtime is rootless Podman on an internal network, drops all Linux capabilities, enables no-new-privileges, exposes no GPU devices, and publishes only `127.0.0.1:58006`.

The current-host collector proves that external egress fails from inside the service container and that cleanup removes all provider containers and the transient internal network.

## Authorization and secrets

The conformance harness creates an ephemeral AutoGPT API key with exactly:

- `IDENTITY`
- `READ_BLOCK`
- `EXECUTE_BLOCK`

The key is never written to canonical evidence. A negative execution attempt requiring `EXECUTE_GRAPH` must return HTTP 403.

FA3 authorization, MCP admission and Host Resource Broker CPU/RAM admission remain external typed contexts enforced by `src/fa3_autogpt_provider.py`; this harness does **not** claim an actual Central MCP network-hop E2E. Accelerator lease is explicitly `NONE_REQUIRED` and the container has no GPU devices.

## License boundary

`autogpt_platform/` is subject to the upstream PolyForm Shield License 1.0.0; Classic/non-platform portions retain their upstream MIT boundary. FA3 records technical admission for the explicitly requested self-hosted provider runtime and does not state a legal conclusion. No AutoGPT Platform source is copied into the FA3 canonical core; the runtime fetches the immutable upstream commit.

## Run

On the actual FA3 host:

```bash
bash bin/fa3-autogpt-current-host.sh
```

A production PASS is valid only when `evidence/receipts/autogpt-current-host.json` is generated by the real self-hosted run and `fa3_autogpt_gate.py --current-host` accepts the finalized cleanup evidence.
