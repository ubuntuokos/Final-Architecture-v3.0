# FA3 External Reference Library

This directory contains controlled external reference sources used for design comparison and pattern discovery. Reference sources are not FA3 runtime, build, release, or authority dependencies unless a separate canonical provider/runtime materialization explicitly says otherwise.

## Active references

- `FA3-REFERENCE-CLI-ANYTHING-001` — CLI-Anything Agent-Native Application Control Reference Source (`docs/references/cli-anything/`).

## Governance rule

A reference may inform an FA3 design, but it cannot grant canonical, security, admission, execution, or resource authority. Any code or runtime behavior adopted from a reference must pass the applicable FA3 semantic mapping, supply-chain/security review, admission, conformance, and evidence requirements before it becomes part of FA3.
