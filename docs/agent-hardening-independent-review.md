# FA3 selective independent evidence review and Control Center projection

Extend the existing Goal Execution Foundation's criterion-level provenance prechecks with checker-separated independent evidence reference validation, using an injected **existing canonical Evidence/Gate binding**. The verifier callback must fetch canonical evidence and authenticate the criterion, goal revision, digest, artifact, verifier and separate checker. No agent-authored receipt or token grants final completion. The projection is owner-only, atomic, non-authoritative and never claims VERIFIED.

Control Center/Agent Action Center reads only a guarded local projection, always clearly labelled as **CANONICAL GATE REQUIRED**. The UI cannot approve or close goals. This is not a new desktop application, model router, memory store, durable owner or evidence authority.

The current implementation is source-level plus a read-only GUI projection. Before production use, wire the verifier callback to the actual authenticated Evidence/Gate and qualify the GUI backend on current-host. No fabricated promotion.

Hardware Audit: CPU-only viable; 0..N accelerators, vendor neutral; all actual resource placement remains HRB-owned, without display GPU automatic enrollment or host tuning. No new capability; baseline 175. No donor code imported.
