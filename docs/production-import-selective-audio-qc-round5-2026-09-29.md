## S4.2 contract: evidence is always distinct from proposed method
The new `canonical/schemas/selective-audio-qc-plan.v1.json` and pure `src/fa3_selective_import_audio_qc.py` compile the **existing** S1/S2/S4 preview objects into a typed QC checklist. They do **not** read media, run FFmpeg, call a model, authenticate a receipt, select a provider, grant publication, or mark physical current-host PASS. The only currently produced outcome is **QC_REVIEW_PLAN_ONLY** with `publish_audio=false` and `execution_authorized=false`. Future runtime evidence is validated through **existing** Security, Audio, UAF, HRB, Model Router and canonical Evidence authorities, not by trusting caller-supplied booleans or opaque receipt strings.

- **Claimed discrete original track**: require canonical independent source-stem attestation, matching source/stream hashes, original rational timebase and sample/channel scope, exact source/target format QC and user-authorized publication. External metadata is an unverified claim until evidence is checked.
- **Proposed estimated stem**: independent source legal status, model/checkpoint hash and admitted exact stem ontology, HRB and Model Router current-host eligibility, audio bleed listening review and objective reference-based metrics **only if isolated reference stems exist**. Absent isolated ground truth, do not invent SDR/SI-SDR or report classification/CLAP scores as isolation proof.
- **Denoised speech**: separate speech intelligibility review, source-frame alignment, preserved intended ambience policy and explicit guard that a denoiser's discarded residual is **not** a requested clean ambience/SFX stem. RNNoise is a *previously known donor*, not a newly approved default provider.
- **Missing / ambiguous / unsupported**: remain blocked or require explicit operator source-track selection; never silently publish an unsupported leaf or deliver unrequested sound/video from an internal transcription demux.
- **Relink and normalization are orthogonal**: optional Chromaprint suggestions require original source SHA-256 verification or manual approval, and libebur128 can flag loudness/peak discrepancies but is not a provenance or voice quality metric.

No transcript-only or caption-only plan may publish media as a hidden side effect. Only explicitly requested, independently approved derivative leaves are handed to target FA3 apps. Immutable originals and source-relative sample/PTS/timebase identifiers survive all outputs and downstream translation.

## Dependency-ordered implementation and completion gates
1. **S4.2 preview (this slice):** typed independent QC requirements for exact/estimated/denoised/unsupported branches, negative tests preventing caller-claimed authority, and source-key-unique donor capture. All gate results start PENDING/UNSUPPORTED. Requires source hash and preflight constraints from S1/S2.
2. **S4.3 physical source inspection:** wire only through the existing `file.convert.inspect`, Security and Evidence receipts, using explicitly selected real source tracks and protected scratch storage; expand golden fixtures for mono, stereo, 5.1, drop-frame, VFR, BWF offsets and original mixed music/singing/dialogue.
3. **S4.4 admitted processing:** exact original stem extraction first; optional existing Demucs and independently admitted specialist classes only when source model weights/license, runtime capability, CPU-only path, HRB GPU policy and explicit per-leaf opt-in have real evidence. No Conda/Mamba, no paid dependency, no model-selected auto GPU enlargement.
4. **S4.5 independent per-output QC:** fixture-based original-vs-output sample/timebase tests; optional loudness/true-peak and sample-file readback; manual bleed/intent judgment, objective reference metrics only with verified isolated references; target-app import/open. A QC score never authorizes a provider or publication.
5. **S4.6 publishing and native roundtrip:** separate user consent and canonical Evidence gates for each requested leaf. Preserve unsupported states, approved partial imports, immutable source and full loss receipts. Editable whole-project claims require same-format reverse-export proof; WAV/MP4/SRT derivatives alone are not native project interchange.
6. **Exact-head release:** reconcile #528 with current main by normalized source key, regenerate/adopt release projection for the final donor count, run Canonical/Promotion, Reuse Discovery, distribution/license, source-specific static/negative tests and real current-host physical GUI/API/E2E independently. No static check alone changes application/provider/model admission.
