# FA3 MLT Extended Media + Digital Human integration

## Scope

This materialization strengthens the preserved MLT media/timeline execution path without turning MLT into an AI provider, provider router or editorial authority.

MLT remains a permanent parallel engine beside the FA3 Native Media Composition Engine. Kdenlive remains the human editorial-state owner and OpenTimelineIO remains the canonical editorial interchange.

## Extended MLT service boundary

The shared profile `FA3-MLT-EXTENDED-MEDIA-SERVICE-001` defines three adapter forms:

1. native MLT service when the implementation is suitable and admitted;
2. isolated sidecar worker for sandboxed render/processing;
3. materialized content-addressed media plus typed metadata.

AI inference is never implicitly embedded into the MLT process. Model/provider selection remains Model Router authority and local accelerator placement remains HRB authority.

## HyperFrames donor use

`FA3-DONOR-HYPERFRAMES-001` is used as an architecture pattern for deterministic web-to-video rendering, editable-source preservation and isolated render projection. The canonical usage edge is `FA3-USAGE-HYPERFRAMES-MLT-EXTENDED-MEDIA-001`.

No HyperFrames source is copied and no HyperFrames runtime is admitted by this change. A future executable adapter must pass exact License & Rights, Security, Software Coexistence, Hardware Safety and physical Current Host gates.

## Digital Human / HeyGen projection

`FA3-DIGITAL-HUMAN-PROVIDER-FABRIC-001` defines provider-neutral digital-human, lip-sync, dubbing and translation contracts. `FA3-PROVIDER-HEYGEN-001` is an optional remote provider projection only.

The static reference planner deliberately performs no API call. Remote execution requires:

- provider/runtime admission;
- explicit user cloud/billable-job approval;
- Secret Broker credential projection;
- face/voice/likeness/avatar/motion rights decision;
- provider-job provenance and result hashing;
- no silent fallback.

HeyGen-generated media is a derived asset. It can enter an editable MLT/Kdenlive timeline only through the existing typed timeline mutation/dry-run/diff/approval path.

## Live avatar boundary

Realtime avatar sessions belong to the realtime/streaming fabric. Only an explicitly recorded/materialized media artifact crosses into the offline MLT editorial path.

## Current Host

This PR is a static architecture/reference materialization. It claims no provider activation and no physical Current Host PASS. The capability baseline remains 175.
