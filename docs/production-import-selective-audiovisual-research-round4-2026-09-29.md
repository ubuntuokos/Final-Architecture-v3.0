## Integration into the exact existing 17-output contract

Do not add an 18th selector or a second data owner. The same three source-family menus (4 text, 6 audio, 7 video), cross-cutting 0/1/N language overlay, project-link / editable-subset / hybrid intake and optional live source mode remain unchanged. Add only **operator-selectable capability profiles** under existing child `SelectiveImportRequest` and `Audio Source Separation Fabric`:

1. **Original-first.** Inspect author-provided dialogue, vocal, score/music, ambience, SFX and channel/object tracks. Prefer exact authorized *original* track export with source sample index, layout and video rational PTS. A separate score/music stem or isolated SFX already in the source requires no generative model.
2. **Locate without pretending to separate.** Existing inaSpeechSegmenter/CLAP/Librosa/PySceneDetect may propose source-time ranges and text-matched target events. A target label is an `ANNOTATION_PROPOSAL`, not an isolated stem. Mixed singing, speech, music, designed SFX, genuine ambience and unwanted equipment noise may overlap; no destructive exclusivity.
3. **Declare stem ontology before any model.** Existing Demucs currently supports its approved drums/bass/other/vocals taxonomy, **not** pure isolated speech, pure singer, independent source ambience or SFX from arbitrary mixes. BS-RoFormer variants may declare separate music stem classes only if an *individually admitted checkpoint* truly produces them; source-conditional MMAudioSep remains non-runnable research until weights, CPU-or-approved-HRB path and quality evidence exist.
4. **Explicit estimated-audio path.** When no verified discrete source track exists, offer only independently admitted model/class-specific **`ESTIMATED`** derivatives with bleed/artifact QA, optional operator side-by-side listen, and **per-output** approved acceptance. If the requested exact class is unavailable, return `UNSUPPORTED` for that leaf, never substitute a denoiser's removed noise as isolated ambience or mix multiple incompatible model outputs without permission.
5. **Original transcript and translation fan-out.** Existing Whisper/STT → corrected Subtitle Studio cue/segment ID → Language Fabric translation 0/1/N BCP-47 targets → language-specific glossary/terminology QA. Traduko-style pause/approve/re-run UX maps to existing Temporal activities and immutable original+derived revision graph. Only requested outputs enter downstream FA3 application inboxes; internally extracted audio for transcript-only requests stays ephemeral.
6. **Separate sync, meaning, and sound quality.** Retain source PTS/sample index for audio/video association; evaluate timing and subjective bleed separately. A perfect AV-sync score does not imply clean SFX/music, and COMET/CLAP/SONAR similarity does not prove faithful translation or restore missing original data. The operator sees separate badges `ORIGINAL_EXACT`, `ESTIMATED`, `REVIEW_REQUIRED`, `UNSUPPORTED`, `BLOCKED`.
7. **Live-specific containment.** For `LIVE_CAPTIONS + NO_AV_FETCH`, caption-only output must ingest **zero audio/video bytes**. Existing authorized HLS/EBU-TT Live/WebVTT/OBS intake may share timing/translation logic but cannot silently download embedded AV, re-broadcast or open a network listener.

## Required negative fixtures

- Speech over sung vocals + music + road ambience + designed explosion: classifier labels do not count as extracted separate audio; optional source-separated vocals do not imply clean speech or pure effects.
- A successful denoiser with audible room ambience removed: its *noise residual* cannot satisfy `AMBIENCE_AND_SFX`.
- Transcript-only import from encrypted or unauthorized video: no audio/video published; deny any external URL or unauthorized cloud model call.
- BS-RoFormer checkpoint missing/404, unlicensed, mismatched ontology or default-path auto-download; no silent model fallback or GPU enrollment, preserve unrelated approved output leaves.
- A 90-minute mixed-FPS video with source BWF offsets and live caption corrections: all chosen outputs preserve rational source positions; updates invalidate only affected language/stem descendants.
- Independent EBU-TT Live source caption-only with `NO_AV_FETCH`: assert **0 AV worker launches and 0 AV bytes**, even under reconnect, missing caption metadata and provider/endpoint redirection.
- Source VSE OTIO adapter successfully parses but drops nested edit/transition or timewarp: no editable-project PASS; retain the original and disclose per-feature losses.


## R4-B preliminary implementation on #528 (preview-only, not a working converter)

The dependency package for the **first inspect/typed-preview slice** now has an executable, side-effect-free reference under [`canonical/schemas/selective-production-import.v1.json`](../canonical/schemas/selective-production-import.v1.json) and [`src/fa3_selective_import_preview.py`](../src/fa3_selective_import_preview.py), with [`tests/test_selective_import_preview.py`](../tests/test_selective_import_preview.py). This **does not** replace the existing Tools/File Conversion inspection or live-source schema. The pure `preflight_preview(request)` function does not read project files, request network sources, select providers/models, open GPUs, publish outputs or authorize execution; it rejects malformed family-scoped selectors and policy fields, builds only `PENDING_*` output leaf previews, and leaves actual format/model/rights/HRB/Evidence proof to existing authorities. It supports 17 exact UI choices and a separately bounded set of 256 target-app/source-range-specific delivery leaves, to avoid treating several destinations as an 18th selector. The AUDIO and VIDEO menus legitimately share the literal `TRANSCRIPT_ONLY`, so identity is a **(source-family, selector-id)** pair; text-language overlays remain independently available on audio/video transcripts.

The pure checker is intentionally **not a full implementation of JSON Schema**, inspection, admitted codec pair validation, a Model Router or a recording license check. The existing `live-production-source.v1.json` still owns independent-caption verification, source protocol, `NO_AV_FETCH`, rights and live capture permissions. Full schema-validation libraries, real source inspection, app targets and independently signed physical current-host tests remain the next gates. All submitted plans stay `PREVIEW_ONLY` with `execution_authorized=false`.
