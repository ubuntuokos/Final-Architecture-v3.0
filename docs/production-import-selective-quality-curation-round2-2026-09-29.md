## 1. The new gap: "selected content" is three different problems

1. **Detect / localize**: find speech/music/noise candidates, explicit speaker boundaries, beats, silences, ambience/event tags, scene changes and source-language spans. This does *not* isolate a signal, prove singer identity or validate a transcript. Store source-time-aligned *proposals* with uncertainty.
2. **Extract / separate**: copy **verified original discrete tracks** losslessly where possible. Otherwise an independently admitted specialist under existing Audio Source Separation Fabric may synthesize **estimated** instrumentals, speech/singing or ambience/SFX stems. No source-track evidence plus no admitted stem schema means `UNSUPPORTED`, never fake `EXACT_VERIFIED`.
3. **Align / evaluate**: forced-align validated transcript to original audio for word/cue timing; produce language-specific derivatives using existing Language Fabric, preserving common segment IDs. Structural checks, signal-contamination/quality checks and human editorial review are *different* proof types; a model's confidence or embedding similarity alone cannot approve content or bypass canonical Evidence.

### Source-time and localization invariant

Use rational source audio sample/sample-rate and video PTS/timebase plus source track/channel identity; preserve original drop-frame/VFR information. Segment candidates store `source_start`, `source_end`, `proposed_kind`, `classifier_ref`, `confidence_when_calibrated`, `human_review`; all metadata are attached to the existing CreativeProjectGraph / Subtitle Studio / Asset Graph. No second segment or translation authority. Speech, singing, music, ambience, SFX and *undesired noise* are **separate ontology types**, and may overlap. No exclusive classifier is allowed to claim that singing has been isolated merely because it was tagged as music.

## 3. Add to the 17-option single-request DAG

| Ordered stage | Explicit design choice | Independently required proof |
|---|---|---|
| Intake/inspect | Existing Tools `file.convert.inspect`, local read-only source digest, consent and media rights. Distinguish native source tracks from flattened master. | Versioned source manifest, trusted local input policy, archive/path rejection, no external egress. |
| Candidate segments | Optional inaSpeechSegmenter, sound-event/CLAP, silence/scene and librosa references mapped to existing Audio/Video metadata. | Source PTS/sample alignment; *singing tagged as music* does not count as speech-vs-singing isolation. Human-editable segment ranges. |
| Deterministic extraction | First prefer original discrete dialogue/music/SFX/ambience tracks, text passages, verified image sequences and FFmpeg picture/audio demux. | Exact source channels, source track identity, frame and duration/timebase QC, unrequested intermediates not delivered. |
| Specialized separation | Existing Demucs/Audio Source Separation ontology, optional independently admitted specialist **only when its exact supported stem classes match requested output**. | Real current-host model/weights+provider+HRB proof, target-specific source contamination measurement when ground truth exists, otherwise qualitative user review and `ESTIMATED`. |
| STT and timed alignment | Existing STT and Subtitle Studio + optional verified forced alignment (MFA reference pattern) for correctable text. | Code-switch/overlap/whispering/singing hard negatives; preserve corrected words as user edits, no transcript hallucination labeled exact. |
| Translation fan-out | One original source-linked transcript -> 0/1/N explicit BCP-47 targets via existing Language Fabric; one approved terminology revision per production. | Roundtrip **semantic** review/terminology and subtitle fitting per language; machine backtranslation only advisory. Original revision immutable. |
| Selective publish | One `SelectiveImportReceipt` per requested output under existing canonical Evidence and Asset Graph; Director/Workforce/UAF/Temporal/Logistics deliver only chosen outputs. | Requested vs produced matrix, explicit `SKIPPED_WITH_APPROVAL` for partial, per-output digest, rights, accepted quality, source app version. |

### Concrete edge cases

- **One source, many exports**: user chooses picture-only frames 01:02–02:13, French original transcript plus Hungarian/German translations, instrumental track and stage ambience. Shared demux/STT executes once; each chosen leaf has separate lineage and quality. If SFX is inseparable in this take, mark just that leaf `UNSUPPORTED`, keep all other approved leaves independently available; never infer SFX from denoiser's leftover.
- **Singing under dialogue**: segmentation might label the whole span speech and assign song to music. Only original isolated stems or approved source-separation provider may deliver separate singing and speech; otherwise `UNSUPPORTED` for this requested distinction. If unverified, do not silently substitute vocals for speech.
- **Silence is intentional**: silence-triggered scene suggestions must never auto-remove quiet frames or classify them as blank; human scene/shot decisions and existing OTIO remain authoritative.
- **Source text with several languages**: preserve per-segment language tag, scene/paragraph IDs, proper nouns, and original alongside optional one/many target locales; translation has its own review/expiry graph.
- **Ambience vs noise**: ambience, designed SFX and unwanted recorder noise can overlap. Never derive a sound-effects library entry from a denoiser residual; require source stem or separately admitted target-conditioned extractor with explicit contamination label.
