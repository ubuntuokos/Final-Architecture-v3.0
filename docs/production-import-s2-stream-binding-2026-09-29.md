## S2.1 extension: source-text audio fallback and exact publication boundaries

An AUDIO source without subtitle tracks can derive a TEXT output from its audio for the existing STT/Language Fabric, and VIDEO TEXT can select either original timed-text or an audio stream. When both exist the preview requires explicit operator track choice; it does not silently claim that subtitles and spoken audio agree. Derived text from audio is an internal-only audio dependency, never a publishable AV product. An explicitly selected full-video output can include the chosen original video, audio and subtitle streams together, but a truly silent source does not advertise a publishable audio track. Signed negative original start PTS are retained rather than clamped or rounded. New synthetic negative/positive tests cover these paths; inspector authenticity, execution, translations and real-media output still require independent existing FA3 authorities and physical current-host E2E. No new donor, selector, capability or runtime authority is introduced.

S2.2 text-only exception: an inspected original TEXT document may have an empty media-stream inventory; AUDIO/VIDEO with zero streams are rejected. Source TEXT cannot bind an unrelated audio or video stream. This closes a preview-only document-import dead end and does not relax rights, hash or inspector receipt checks.
