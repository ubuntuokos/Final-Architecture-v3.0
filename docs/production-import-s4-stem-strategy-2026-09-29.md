## Priority and precise meanings

1. Prefer an original **discrete** source track with the exact requested ontology class: `SPEECH`, `SINGING`, `INSTRUMENTAL`, `MUSIC`, `AMBIENCE`, `SFX`, or `AMBIENCE_AND_SFX`. A `VOCALS` track cannot by itself prove isolated speech or isolated singing. An `AMBIENCE` track cannot silently satisfy a request for `AMBIENCE_AND_SFX`.
2. Require the existing `file.convert.inspect` source digest, stream-index, source-referenced original rational timebase and independently authenticated source-attestation receipt. A ref present in a user-supplied inventory is a **claim until verified** by existing Evidence and rights/security authorities, not `ORIGINAL_EXACT`.
3. Where no exact original exists, display candidate-only `ESTIMATED` strategies solely for a matching advertised **specific stem ontology**, only after an *explicit per-output opt-in to preview* by the operator. Each candidate names an opaque proposed provider ref, weight SHA-256, ontology and license-review ref; these are not verified merely because the fields are present. No automatic download, fixed checkpoint, automatic model switch or invisible fallback.
4. A `DENOISED_SPEECH` derivative uses its own denoiser/quality review path, never a source separator. Denoiser removed-noise residual is not user-requested room ambience or sound effects. CLAP/inaSpeechSegmenter classification locates or labels a probable sound; classification is **not extraction**.
5. Preserve the original and record a separate independent quality receipt for each resulting stem: before publication evaluate contamination/bleed, distortion, source synchronization and operator review. Metrics such as SDR require an actual reference stem; embedding similarity or self-reported model quality cannot prove clean music/SFX.
6. For `TEXT` or `TRANSCRIPT_ONLY` leaves, use existing S3 plan and **publish zero unintended media**. Keep internal demuxed audio temporary and enforce approved retention. Existing S4 preview returns `publish_audio=false` for all leaves until separately admitted conversion and explicit output approval.
7. Existing Director/Workforce + Temporal own dependency lifecycle; existing UAF, Central MCP Gateway, Secret Broker, Model Router, HRB, Security Governance, Asset Graph, Logistics and Evidence retain their exclusive responsibilities. Enforce CPU-only viability of the baseline; if any other GPU/NPU exists, use the display GPU for AI only on explicit model-and-task assignment.
