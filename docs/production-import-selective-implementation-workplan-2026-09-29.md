## 1. End-user interaction: one input, selective typed deliverables

- Three existing selector families are unchanged: TEXT (4: original; one requested language; N requested translations; original plus N translations), AUDIO (6: full; transcript only; speech or singing; instrumental music without singing; ambient/SFX; denoised speech), VIDEO (7: full; silent picture; full audio; spoken transcript; music/instrumental; ambient/SFX; selected frames or scenes). Exact Hungarian labels and stable enum IDs have **one authority: the parent 17-selector plan**.
- These are independent *checkboxes*, and one selection can yield more than one output only where explicitly requested (e.g. one transcript per approved target language). The same text language controls must apply to original documents **and** AUDIO/VIDEO `TRANSCRIPT_ONLY` derivatives.
- Shared controls: source application/version and protected immutable snapshot or authorized read-only link; whole project or selected source range; document paragraph/scene, movie shot/timecode/frame, audio sample/track/channel, independently identified speaker/singer; target BCP-47 languages, chosen glossary/revision and protected terms; per-output target FA3 application, native versus derivative output format, original retention, privacy/rights/egress approvals, output acceptance.
- Distinguish `SOURCE_ORIGINAL`, `EXACT_VERIFIED_DISCRETE_TRACK`, `LOSSLESS_DEMUX_WHEN_VERIFIED`, `ASR_ESTIMATE`, `TRANSLATED_DERIVATIVE`, `MODEL_SEPARATED_ESTIMATE`, `NOISE_PROCESSED_DERIVATIVE`, `ANNOTATION_PROPOSAL` and `INSPECT_ONLY`. Satisfying a video transcript-only request may internally demux audio but **must not publish** that unrequested audio.
- Support all three existing migration modes: external-project read-only link; separately demonstrated editable native FA3 project import; and hybrid linking for parts that cannot safely roundtrip. Also permit archival-copy, derivative-only, partial import with individual requested/produced comparison and explicit skipped-output approval. Never equate derived WAV/SRT/MP4/PDF with an imported fully editable native project.

## 4. Single-source typed DAG, failure semantics and detailed contracts

1. `INSPECT`: immutable or read-only source, hash and scoped authorization, format/version, linked media completeness, source language(s), rights, target destinations, live external links, human-verified discrete tracks. Quarantine macros, plugin execution, archive bombs, path traversal, network URLs and untrusted project instructions.
2. `PLAN`: validate each requested selector against exact input/output and target-app version, required language packs, format-pair allowlist, available admitted specialists, CPU-only path and independent HRB leases. Classify source channels as `dialogue`, `singing`, `instrumental`, `music`, `ambience`, `sfx`, `unwanted_noise`; allow overlapping labels. Produce explicit per-leaf quality, support and expected loss.
3. `STAGE`: Logistics content-addressed staging, cross-host source hash and ACL receipts; never mutate original or retain hidden publishable intermediates. For large source files, chunked/streaming processing must retain exact part-to-source identity.
4. `SHARED_DECODE`: decode/demux once per selected scope and sharing class. Keep rational video PTS/timebase, drop-frame/VFR source rules and audio original sample index/rate, channels and BWF offsets. Do not implicitly mix channels, change pitch, tempo or color space.
5. `BRANCH`: TEXT → structured Document/Story and approved Language Fabric translation 0/1/N; AUDIO → exact original tracks when available, optional independently admitted stem separation, Whisper/STT, Subtitle Studio and admitted denoise only when selected; VIDEO → picture-only/full audio, bounded selected stills/scenes, or the shared audio sub-DAG. `ONLY_TRANSCRIPT` delivers no new media. `MUSIC_NO_SINGING` / `AMBIENCE_SFX` require exact isolated original stems or an explicitly supported and separately admitted *estimated* source separation mode; otherwise return `UNSUPPORTED` for that leaf.
6. `ALIGN`: assign immutable source segment/scene IDs before translation. Source transcript corrections invalidate only dependent translations and captions. Use ffsubsync-style alignment to original audio only as an approved candidate. Cross-language word alignment is advisory; preserve per-segment source locale and code-switching. For overlapping voices or singing, visible QC review is required.
7. `QC`: one output-specific receipt with input/output hashes, source timebase and ranges, model/weights hashes, adapter/format pair, execution class, uncertainty/quality, human review, language/glossary revision and `EXACT_VERIFIED` vs `ESTIMATED`. Reference-based separation scores exist only with independently known isolated reference stems. WER/CER require corrected text; translation COMET/semantic similarity is advisory and requires accepted model/checkpoint and human review on high-stakes scripts.
8. `PUBLISH`: explicit approval and independent Evidence gate before per-output delivery into Story, Subtitle Studio, Audio, Music, Video/QuickClip, Photo, Shot Designer or archive. Compare all requested vs produced selectors and each requested language; a missing output remains `BLOCKED`/`UNSUPPORTED`/approved partial, not silent success. Versioned rewind preserves original and old derivatives. No unsolicited cloud upload or external writeback.

Selective invalidation: changing source samples invalidates only intersecting leaf descendants, changing glossary invalidates relevant language outputs, changing subtitle alignment invalidates captions but not untouched source audio, changing separation model invalidates its estimated stems and downstream transcripts only where sourced from them. Independently human-approved outputs freeze until reapproval.

## 6. Mandatory test matrix and operator acceptance

- **One film, four different outcomes**: import only silent frames/scenes, original English spoken transcript and Hungarian/German translations, instrumental soundtrack, and requested isolated ambient/SFX. Original named tracks are exact; a flattened stereo mix must show estimated/unsupported stems rather than fake exact output; all delivered outputs keep matching shot/timecode lineage.
- **Speech vs singer overlap**: dialogue over singing; classification proposal alone cannot claim independent singing, instrumental or ambient stems. If requested effect is unsupported, other selected outputs may still complete after explicit partial approval.
- **Dubbed/code-switched script**: original transcript/source language per segment, name and glossary preservation, retranslation of one changed line invalidates only affected target-language derivatives; corrected source has human edit origin.
- **Timebase edge cases**: mixed frame rates, VFR, drop-frame, discontinuous timecodes, silence, multichannel 5.1, BWF offsets and long recordings; original/derived frame/sample offsets checked against golden fixtures.
- **Preservation and interoperability**: editable external project source hash remains unchanged, approved same-format reverse export has feature-level retention report; PDF/MP4/WAV/SRT are never used to claim full editable project migration.
- **Privacy and hostile input**: no unauthorized external fetch, untrusted script/plugin/path execution, prompt instructions in subtitles ignored, no Secret Broker bypass, review hidden intermediates/retention, deny unadmitted weights or cloud translation.
- **GPU and lifecycle**: CPU-only mandatory and HRB-authorized accelerator admission; display GPU only automatic for AI if no other GPU and no NPU, otherwise only explicit in-app model-and-task assignment. No silent fallback, no risky hardware tuning. Verify pause/cancel/resume/revoked approval/partial failure and host noninterference.
