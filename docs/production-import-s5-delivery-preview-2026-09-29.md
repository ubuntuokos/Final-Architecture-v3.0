## Purpose and non-claims
`src/fa3_selective_import_delivery_preview.py` builds one shared *planning* manifest from all existing selective import planning stages for one stored file/external project. It is subordinate to existing `FA3-FILE-CONVERSION-001`, Creative Project Workflow, Language Fabric, Audio Separation, UAF, Security, HRB, Model Router, Logistics/Asset Graph, and canonical Evidence. **It does not execute codecs/STT/translation, authenticate inspector receipts, approve a model, publish media, open an application, perform native project roundtrip, or demonstrate physical current-host PASS.**

Each requested source-family/selector/range/destination generates one or more typed *deliverable intents* (0/1/N original or translated text, original media projection, or one QC-gated stem). The user selects combinations of the **unchanged 4 TEXT + 6 AUDIO + 7 VIDEO options**. Transcripts from AUDIO/VIDEO inherit exactly the same TEXT language controls without adding a new selector. Every deliverable preserves parent selector ID, requested destination and delivery class, original source/stream references and rational timebases, source range, pending gates and independent non-executable status. All output publication booleans are false; requested media intent is a separate informational field, not permission.

## Selective conflict and isolation rules
- Internal transcription demux is not a requested media delivery. A transcript-only leaf requests only TEXT, and both `publish_audio` and `publish_video` are false. A separately selected video or audio output is an independent leaf requiring its own authorization.
- Distinguish original asserted tracks and optional estimated specialist models using the existing S4/S4.2 provenance and QC states. Audio event detection, loudness, fingerprint similarity, denoiser residuals and external claimed model stem classes confer **no source isolation or model approval**. Unsupported stems remain unsupported; no silent substitute.
- A source-binding group is a deterministic **inspection-sharing hint**, not authorization to reuse a media decode workspace across security classifications, destinations, users, jobs or hosts. Real sharing requires existing Security/UAF/HRB and data policy clearance.
- Show a separate locale-specific output for each explicitly requested translation and original variant, preserving the S3 duplicate-destination review states. `auto` source languages remain unverified. Editable project requests add exact format/version/feature reverse-roundtrip verification; WAV/MP4/SRT delivery is never itself editable project import.
- Retain explicit rights, original source SHA-256, inspector receipt reference, target adapter gate, software coexistence, canonical Evidence and human publication approval for **each deliverable**, and require an existing UAF cross-app authorization if missing. Caller-provided refs remain *opaque unverified claims* until the existing authorities inspect them.
- LIVE_VIDEO/LIVE_AUDIO/LIVE_CAPTIONS are deliberately rejected by this stored-source compose function; the independently governed live-source preflight and capture receipts must precede a future shared composer extension. Never silently fetch AV for independent caption-only input.
