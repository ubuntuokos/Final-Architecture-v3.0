## A. User-visible scope and producer/consumer boundaries

The exact **17 Hungarian labels and stable IDs** remain owned solely by the parent plan: 4 text selections, 6 audio selections, 7 video selections. This extension adds no new top-level selection, only optional settings and quality receipts. Multiple selected outputs share one source, but each delivered artifact is independently versioned and accepted. Text language choices apply identically to document text and explicitly requested audio/video transcripts.

Cross-cutting controls: source file/project and immutable digest, original vs chosen BCP-47 target languages (1..N), glossary revision and protected names, chosen scene/range/track/speaker labels, destination app and file format, confidence/uncertainty visibility, source rights/consent, delivery-only versus *proven* editable import, operator review, and approved source-writeback policy. Never manufacture diarized identity or silently upload protected material.

Existing services own work: Tools/File Conversion #195 and historically proposed VERT-style offline WASM/native execution **folded into one existing facade**, specialized FFmpeg/Document/FA3-3D-GEOM/GRRE providers, existing Language Fabric/Bridge, Whisper STT, Caption/Subtitle Studio, Audio Source Separation and admitted Demucs/other adapters, Video Editor/QuickClip/OpenTimelineIO, Production Graph, Director/Workforce+Temporal, UAF/MCP, Model Router, HRB, Logistics and Security/Evidence authorities. ## C. Correct transformation and quality semantics

| Requested selection | Preferred deterministic source | Estimated fallback and mandatory evidence | Not equivalent to |
|---|---|---|---|
| Original text / original timed transcript | Exact original document segments; for media use explicitly authorized source-language STT where no supplied transcript exists | STT ASR_ESTIMATE, segmented source timebase, corrected original intermediate retained as per retention policy | Perfect verbatim transcription from mixed audio |
| One/multiple/original+translations | Existing canonical translation packages and glossary, **one original segmented intermediate** | Each BCP-47 target is an independent TRANSLATED_DERIVATIVE with protected names, segment alignment, consistency checks and human review for critical legal/creative text | The original author's words or independently proofread dubbing script |
| Full audio from video | Demux existing discrete track, preserve sample rate, layout, channel-order, BWF timecode where available | If decode or channel mapping changes bytes, mark transformed and report; do not claim bit-exact after codec transformation | Full editable DAW project |
| Speech, singing, music without singing | Original source dialogue/vocals/music stems where delivered | Admitted separator must declare actual stem ontology and tested reference quality, leakage, phase and artifact receipts; speech and singing need **different** evidence from generic vocals | A four-stem Demucs vocals output containing only speech or an exact instrument stem |
| Ambience and sound effects | Source-authorized ambience/foley/SFX track(s), linked cue IDs | Experimental event-guided proposals may be **INSPECT_ONLY** until an independently admitted source-isolation provider proves each requested class; acoustic classifier merely proposes time ranges | Denoiser residual/noise track |
| Denoised speech | The source dialogue stem with an original backup | Optional admitted speech enhancement, loudness and intelligibility listening QC; side-by-side original and denoised excerpt | Preserved original acoustic environment |
| Silent video, audio-only, frames/scenes | Exact stream maps where supported, selected source frame PTS and original rational timebase; editorial source playlist | If transcoded or AI detected, record inferred cut/scene boundaries, VFR/drop-frame conversion and range deltas | Full native/editable production project |

Fidelity labels must be machine-checkable: ORIGINAL_TRACK_EXTRACT, LOSSLESS_TRANSFORM, ESTIMATED_SEPARATION, ASR_ESTIMATE, TRANSLATED_DERIVATIVE, PROJECTION_ONLY; output status EXACT_VERIFIED, ESTIMATED, DECLARED_LOSS, INSPECT_ONLY, UNSUPPORTED, BLOCKED. Never promote generated audio or machine-translated content to EXACT_VERIFIED solely due to similarity scores.

## D. Reuse, change management and quality gates

Compute per-output cache eligibility from source file SHA-256 **and immutable source range/track IDs, adapter version, admitted model+weight digest, glossary+translation policy revision, source/target locales, requested stem ontology, authorized processing rights and quality profile**. Same content hash alone is insufficient if the user changes consent, locale, glossary, separation task or source annotations. Cached results must pass current admission and authorization again before being revealed to another app; no global sharing of private intermediate transcripts.

One scoped DAG has shared safe decoding/track discovery, optional shared source-language transcription and separate fan-out branches per target locale, speaker/stem and destination. Each output has a signed original-to-derivative lineage record and data-class decision. Missing one optional derivative never silently drops a requested choice: return BLOCKED/UNSUPPORTED with user-approved partial-commit option; no hidden intermediary is delivered. Changed source segments invalidate only dependent branches. Frozen human-approved subtitle/translation edits are not overwritten by ASR re-runs.

Quality review is **method-specific**, not a universal percentage: translation terminology and human scene-context review, STT language/cue alignment and code-switch/speaker overlap tests, loudness/channel/phase alignment for separated stems, ambience/SFX false extraction checks and human audition, exact selected frame PTS/color metadata, reproducible source-versus-output hashes. Machine quality tools may flag samples but may not approve unreviewed creative or rights-sensitive content.

**Q4 source-aware audio:** default to discrete original stems; existing Demucs provider only for claimed stems. Any additional model or DeepFilterNet/RoFormer/VR/MDX implementation requires full model/license/provenance, CPU/HRB capacity, current-host quality and hardware safety gates. **Q5 GUI + cross-application handoff:** add selected-language and stem-target subcontrols beneath the 17 existing Qt6/QML selectors. **Q6 regression matrix + real host:** tests use consent-cleared originals and synthetic adversarial fixtures: one source video yields English transcript + Hungarian/German translated cues + picture-only scene + instrumental + isolated original SFX stem, **only where source/real admitted model supports it**. Negative tests: impossible ambience extraction, Demucs vocals mislabeled speech, SECRET egress, forbidden commercial speech-translation weights, unadmitted model, display-GPU auto-enlistment, output omission, wrong PTS, alternate doc source silently flattened and forged E2E.

**Q7 release gates:** exact-head Canonical/Promotion, Reuse Discovery and donor-index checks, registry identity and release-projection reconciliation; real CPU-only and HRB-authorized optional accelerator current-host tests, actual Wayland UI/X11 fallback, actual source-app subset roundtrip, user-approved selective cancellation/retry/rollback and Software Coexistence/Host Non-Interference. Hosted CI alone is not current-host or professional translation/source-separation proof.

## F. Example production workflow

An editor selects one documentary video, AUDIO TRANSCRIPT_ONLY (source language), TEXT ORIGINAL_PLUS_TRANSLATIONS (HU, DE), VIDEO_WITHOUT_AUDIO (scene 14), VIDEO MUSIC_OR_INSTRUMENTAL_ONLY, and VIDEO AMBIENCE_AND_SFX_ONLY. The inspector detects original stereo master but no separate SFX stems. STT and translation outputs can be proposed with proper authorized local routes, scene 14 silent picture can be deterministically extracted with preserved frame IDs, music-only requires estimated stem quality checks, and SFX-only is BLOCKED unless separately admitted experimental evidence permits an INSPECT_ONLY preview. The operator can approve partial delivery without changing the selected request invisibly. Every output remains linked to immutable source/video timecodes and the original creative project.

**Explicit exclusions:** no second FA3 conversion service or translation scheduler, no unsupported commercial/copyleft/NC code bundled by default, no external speech or media upload by default, no automatic direct model download, no claim that classification equals separation, no new capability ID, no false current-host PASS, no source-file overwrite, no hidden migration of upstream approvals.
